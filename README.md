# PegadaFit — Documentos Legais

Repositório oficial dos documentos legais do app **PegadaFit** — rede social fitness brasileira.

Os documentos publicados aqui são vinculantes para todos os usuários do PegadaFit e regem o uso do aplicativo nos termos da legislação brasileira aplicável: **LGPD (Lei 13.709/2018)**, **Marco Civil da Internet (Lei 12.965/2014)**, **Código de Defesa do Consumidor (Lei 8.078/90)** e demais leis pertinentes.
